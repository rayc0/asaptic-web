Endpoints públicos

Oito maneiras de ler o registro - todas verificáveis por curl, a maioria sem chave.

Os mesmos dados que nosso mecanismo de execução de IA lê. Sem taxa de SDK, sem login no painel, sem barreiras de paginação que não documentamos.

GET/api/v1/healthStatus do feed - contagem de linhas, id da edição, sinalizador de atualidade. O objeto ao qual todo número desta página remonta.
GET/tender/rows.jsonSnapshot completo do registro - todas as 2.536 linhas higienizadas, trilíngue (en / zh-Hans / zh-Hant), atualizado a cada edição semanal. Sem chave.
GET/api/v1/tendersFeed filtrável e paginado - market, category, closing_bucket, value_band, q, cursor. Por padrão mostra apenas licitações abertas (697 no momento) - passe closing_bucket=all para ver as 2.536 completas.
GET/api/v1/tenders/{at_id}Uma linha de licitação pelo seu id Asaptic.
GET/api/v1/tenders/facetsContagens por mercado, categoria, faixa de encerramento e faixa de valor. A forma mais rápida de conferir nossos números - veja acima.
GET/api/v1/spec-coded/{at_id}Pacote técnico restrito. Chamadas não autenticadas recebem um 403 real, com o caminho de acesso no corpo - não um 200 falso disfarçado de demo.
POST/mcpServidor Model Context Protocol, JSON-RPC 2.0. tools/list retorna 10 ferramentas chamáveis, incluindo list_tenders, get_tender, tender_facets, explain_fit, submit_rfq.
GET/llms.txtÍndice do site em texto simples para modelos de linguagem. Esta página tem uma versão gêmea legível por máquina.

Feito também para máquinas

Não apenas amigável para desenvolvedores. Nativo para agentes.

O mesmo registro que impulsiona nossa execução de negociações é legível por seus agentes e modelos - sem scraping, sem análise de HTML, sem adivinhações.

MCP
Model Context Protocol
Um servidor MCP em conformidade com os padrões expõe o registro como ferramentas. Aponte seu agente para o endpoint e deixe-o consultar licitações, cadeias de fornecimento e pontuação de aderência diretamente.
JSON
Feeds estruturados
Cada número público neste site resolve para um endpoint JSON. A página e a API são o mesmo objeto - não há um conjunto de dados de marketing separado.
TXT
llms.txt
Um mapa em texto simples do que é a Asaptic e onde os dados residem, para que os modelos de linguagem nos citem corretamente sem adivinhar a partir do HTML renderizado.
AO VIVOPOST /mcp200 OK
$ curl asaptic.com/mcp -d '{"method":"tools/list"}'
{ "result": { "tools": [ "list_sourcing_lanes", "get_lane_capability", "get_engagement", "submit_rfq", "list_tenders", "get_tender", "tender_facets", "get_spec_coded", "request_tender_access", "explain_fit" ] } }
# resposta real em JSON-RPC 2.0 - os esquemas completos de entrada
# foram omitidos aqui por espaço, o resto é exatamente assim. 10
# ferramentas, sem autenticação. teste você mesmo.
