公开接口

八种读取台账的方式 - 全部可用 curl 验证，多数无需密钥。

与我们的 AI 执行引擎读取同一份数据。无 SDK 成本，无需登录控制台，也没有未公开说明的分页限制。

GET/api/v1/health数据流状态 - 行数、期号、新鲜度标志。本页所有数字的最终依据。
GET/tender/rows.json完整台账快照 - 全部 2,536 行脱敏数据，三语（英文 / 简体中文 / 繁体中文），每期（每周）更新一次。无需密钥。
GET/api/v1/tenders可筛选、可分页的数据流 - 支持 market、category、closing_bucket、value_band、q、cursor。默认只返回未截标的项目（目前为 697 条） - 传入 closing_bucket=all 可查看全部 2,536 条。
GET/api/v1/tenders/{at_id}按 Asaptic id 查询单条招标记录。
GET/api/v1/tenders/facets市场、类别、截标区间与金额区间的计数。验证本页数字最快的方式 - 见上方验算。
GET/api/v1/spec-coded/{at_id}受限的技术规格包。未通过认证的请求会收到真实的 403，响应体附带申请通道 - 不是包装成演示的假 200。
POST/mcpModel Context Protocol 服务器，JSON-RPC 2.0。tools/list 返回 10 个可调用工具，其中包括 list_tenders、get_tender、tender_facets、explain_fit、submit_rfq。
GET/llms.txt供语言模型使用的纯文本站点索引。本页有一个机器可读的孪生版本。

同样为机器而生

不止对开发者友好。原生支持智能体。

驱动我们贸易执行的同一份台账，你的智能体和模型也能直接读取 - 无需爬取，无需解析 HTML，无需猜测。

MCP
Model Context Protocol
符合标准的 MCP 服务器将台账以工具形式开放。将你的智能体指向该接口，即可直接查询招标、供应链路和匹配度评分。
JSON
结构化数据流
本站上的每个公开数字都对应一个 JSON 接口。页面和 API 是同一个对象 - 不存在独立的营销数据集。
TXT
llms.txt
一份纯文本说明，描述 Asaptic 是什么以及数据存放在哪里，让语言模型准确引用我们，无需从渲染后的 HTML 中猜测。
