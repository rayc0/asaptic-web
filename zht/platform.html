公開端點

八種讀取總賬的方式 - 全部可用 curl 驗證，大部分毋須金鑰。

與我們的 AI 執行引擎讀取的資料相同。沒有 SDK 額外收費、沒有儀表板登入，亦沒有未公開說明的分頁限制。

GET/api/v1/health數據流狀態 - 行數、期號、新鮮度標記。本頁所有數字的最終依據。
GET/tender/rows.json完整總賬快照 - 全部 2,536 行已脫敏資料，三語（英文 / 簡體中文 / 繁體中文），每期（每週）更新一次。毋須金鑰。
GET/api/v1/tenders可篩選、可分頁的資料流 - 支援 market、category、closing_bucket、value_band、q、cursor。預設只回傳未截標項目（現時為 697 項） - 傳入 closing_bucket=all 可查看全部 2,536 項。
GET/api/v1/tenders/{at_id}按 Asaptic id 查詢單一招標記錄。
GET/api/v1/tenders/facets市場、類別、截標區間與金額區間的計數。驗證本頁數字最快的方式 - 見上方驗算。
GET/api/v1/spec-coded/{at_id}受限的技術規格套件。未經核准的請求會收到真實的 403，回應內附申請途徑 - 不是包裝成示範的假 200。
POST/mcpModel Context Protocol 伺服器，JSON-RPC 2.0。tools/list 回傳 10 個可呼叫工具，當中包括 list_tenders、get_tender、tender_facets、explain_fit、submit_rfq。
GET/llms.txt供語言模型使用的純文字網站索引。本頁面有一個機器可讀的對應版本。

同樣為機器而建

不僅對開發者友善。更原生為代理而建。

支撐我們貿易執行的同一總賬，您的代理與模型也可讀取 - 無需爬取、無需解析 HTML、無需猜測。

MCP
Model Context Protocol
符合標準的 MCP 伺服器將總賬以工具形式公開。將您的代理指向該端點，即可直接查詢招標、採購渠道及匹配度評分。
JSON
結構化資料流
本網站上每個公開數字都對應至一個 JSON 端點。頁面與 API 是同一物件 - 沒有獨立的市場推廣資料集。
TXT
llms.txt
