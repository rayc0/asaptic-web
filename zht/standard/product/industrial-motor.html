工業電動機中國出口標準

工業電動機——尤其是用於泵、壓縮機和輸送系統的三相感應電機——須符合強制性最低能效標準（MEPS），該標準設定了強制效率等級並限制低效率產品在主要市場的銷售。從中國出口電動機，須證明符合適用效率等級（IEC 60034-30-1下的IE2、IE3或IE4，或等效國家標準），從認可實驗室取得第三方檢測報告，部分市場還要求在進口前向國家能效主管機構登記。電壓額定值、繞組配置及防護等級也須符合當地慣例。以下頁面針對每個覆蓋市場，比較MEPS制度、測試標準、登記要求及標籤義務。

阿根廷（IRAM / S標誌）

  • 阿根廷（IRAM / S標誌） - 工業電動機 · 查看對照
    阿根廷對列名電機類別要求IRAM產品認證（或等效的Certificado de Homologación），並要求按能源秘書處方案對齊IE等級的強制能效標識；CCC認證不被認可。

澳洲（RCM/AS-NZS）

  • 澳洲（RCM/AS-NZS） - 工業電動機 · 查看對照
    GEMS 注冊系統的供應前注冊（澳洲獨有，中國無對應制度）和 RCM 標誌（涵蓋電氣安全與 EMC）是關鍵的市場准入差距；IE3 MEPS 門檻名義上一致，但測試方法和具體數值存在差異。

孟加拉（BSTI / SREDA / BPDB）

  • 孟加拉（BSTI / SREDA / BPDB） - 工業電動機 · 查看對照
    進入孟加拉國的主要差距在於覆蓋產品的 BSTI 認證、BDS 或 IEC 60034 依據、當地能效標籤要求、400 V 三相電網適配及進口文件。

巴西（INMETRO）

  • 巴西（INMETRO） - 工業電動機 · 查看對照
    INMETRO 強制認證及 Lei 10.295/2001 高效要求（IR3）是主要差距；中國電機進入巴西市場前須取得 INMETRO 合格標誌並滿足 ABNT NBR 17094 安全要求。

加拿大（加拿大衛生部 / CSA）

  • 加拿大（加拿大衛生部 / CSA） - 工業電動機 · 查看對照
    出口關鍵差距不只是認證：加拿大採用 60 Hz，工業三相系統常見 600/347 V，因此中國 50 Hz / 380 V 電機在評估 CSA 認證和 NRCan IE3 合規之前，已可能存在電氣不相容。

智利（SEC）

  • 智利（SEC） - 工業電動機 · 查看對照
    SEC強制認證章及製造商註冊是主要市場准入差距；CCC不被智利認可。

哥倫比亞（RETIE/RETILAP）

  • 哥倫比亞（RETIE/RETILAP） - 工業電動機 · 查看對照
    哥倫比亞為 60 Hz 市場。

埃及（EOS / EgyptERA）

  • 埃及（EOS / EgyptERA） - 工業電動機 · 查看對照
    埃及要求列入目錄的工業電動機獲得 EOS 強制 ESQ 標誌和 GOEIC 進口符合性證書；中國 CCC 不被認可。

歐盟（CE）

  • 歐盟（CE） - 工業電動機 · 查看對照
    歐盟生態設計法規 2019/1781 的最低能效（IE3/IE4）以及 LVD/EMC 的 CE 合規是主要差距；許多中國電機低於歐盟 MEPS 等級。

德國（DIN / 聯邦網路局 / 聯邦經濟與出口管制局）

  • 德國（DIN / 聯邦網路局 / 聯邦經濟與出口管制局） - 工業電動機 · 查看對照
    進入德國的關鍵差距是歐盟法規 2019/1781 下的 IE3/IE4 能效合規、低壓與 EMC 指令下的 CE 標誌及歐盟符合性聲明、歐盟境內授權代表或責任經濟經營者，以及應對德國聯網局市場監管。

印度（BIS/ALMM）

  • 印度（BIS/ALMM） - 工業電動機 · 查看對照
    IS 12615:2018 是適用的印度能效標準，FMCS 下的 BIS ISI 標誌是境外製造商在須要認證時的申請途徑。

印尼（SNI / SDPPI）

  • 印尼（SNI / SDPPI） - 工業電動機 · 查看對照
    印度尼西亞的實際差距主要是程序性而非電氣參數：適用範圍內的三相交流電動機需要印度尼西亞 SNI 認證、Pertek/進口清關支持、SNI 標誌和 ESDM 能效標籤；380 V 50 Hz 與中國一致，IE 等級基礎與 IEC 60034-30-1 對齊。

日本（PSE/JET）

  • 日本（PSE/JET） - 工業電動機 · 查看對照
    日本領跑者計畫依據《節能法》要求三相感應電機（0.75–375 kW）達到 IE3 等效最低能效；符合 GB 18613-2020 3 級（IE3）的中國電機在技術上接近該要求，但日本特有的申報義務、JIS C 4034 性能文件及變頻驅動應用的電波法 EMC 合規構成額外差距。

肯亞（KEBS）

  • 肯亞（KEBS） - 工業電動機 · 查看對照
    肯尼亞要求在出貨前在原產地進行 KEBS 強制 PVoC（出口前符合性驗證）檢驗並獲得 KEBS Diamond Mark 品質標誌；肯尼亞採用 KS IEC 60034 電機標準；CCC 認證不被認可。

馬來西亞（ST / SIRIM）

  • 馬來西亞（ST / SIRIM） - 工業電動機 · 查看對照
    SIRIM 強制產品認證、ST MEPS 注冊（最低 IE2，方向為 IE3）、電壓重新定額（380 V 升至 415 V）以及 MCMC EMC 審批是主要差距；中國 CCC 認證在馬來西亞不被認可。

墨西哥（NOM / COFEPRIS）

  • 墨西哥（NOM / COFEPRIS） - 工業電動機 · 查看對照
    墨西哥不能直接沿用 CCC：三相感應電機須按 CONUEE 體系核查 NOM-016-ENER-2016，映射 NOM-001-SEDE、NOM-003-SCFI 等適用電氣安全 NOM，並在 NOM 範圍要求時通過 ANCE 或 NYCE 等獲准機構認證。

摩洛哥（IMANOR）

  • 摩洛哥（IMANOR） - 工業電動機 · 查看對照
    摩洛哥通過IMANOR採納NM IEC 60034標準，並在ANRE/PNEE計劃下遵循IEC 60034-30-1能效方向；由於摩洛哥-歐盟高級地位，CE標誌及歐盟符合性聲明被廣泛接受。

奈及利亞（NAFDAC / SON）

  • 奈及利亞（NAFDAC / SON） - 工業電動機 · 查看對照
    進入奈及利亞的主要差距是 SON MANCAP 認證、奈及利亞三相 415 V 供電與中國 380 V 設計假設的差異，以及 NIS IEC 60034 下的奈及利亞本地文件要求；中國 CCC 不能替代。

巴基斯坦（PSQCA）

  • 巴基斯坦（PSQCA） - 工業電動機 · 查看對照
    進入巴基斯坦的主要差距是列名電動機產品的 PSQCA 符合性、基於 IEC 60034 的文件、採用 IE 等級的 NEECA 能效方向，以及 400/230 V、50 Hz 電網適配；中國 CCC 或 GB 18613 證據本身並非巴基斯坦批准。

秘魯（INACAL）

  • 秘魯（INACAL） - 工業電動機 · 查看對照
    進入秘魯的首要差距是頻率：工業電機必須適用於 60 Hz 運行，中國內銷 50 Hz 電機不能直接相容。

菲律賓（BPS / DTI）

  • 菲律賓（BPS / DTI） - 工業電動機 · 查看對照
    對覆蓋範圍內的三相工業交流電動機，菲律賓差距通常不只是 IE 等級：必須確認能源部 IE2 最低能效、BPS/DTI PS 標誌或 ICC 進口清關、PNS/IEC 60034 依據以及真實 60 Hz 設計。

沙特阿拉伯（SASO/SABER）

  • 沙特阿拉伯（SASO/SABER） - 工業電動機 · 查看對照
    沙特阿拉伯要求最低 IE3 能效（SASO/SEEC 法規參照 IEC 60034-30-1）及 SABER PCoC+SCoC 市場准入合格證書；大多數中國電機滿足 IE3 能效底線，但須在出貨前取得 SABER 證書並核驗 IEC 測試方法的一致性。

新加坡（EMA / 企業發展局）

  • 新加坡（EMA / 企業發展局） - 工業電動機 · 查看對照
    對適用範圍內的三相工業交流電動機，新加坡市場准入重點在能源市場局 MEPS 與註冊、SS 或 IEC 60034 技術證據、本地責任供應商控制、400 V 50 Hz 適配，以及含變頻器或無線功能時的 IMDA 審查。

南非（SABS / NERSA）

  • 南非（SABS / NERSA） - 工業電動機 · 查看對照
    中國電機進入南非的首要門檻是NRCS進口許可證（LoA）——凡屬強制規範覆蓋範圍的電機，進口或銷售前須取得LoA；SABS SANS 60034（採用IEC 60034）為技術標準，DoE能源政策下執行MEPS IE2+方向。

韓國（KC / KATS）

  • 韓國（KC / KATS） - 工業電動機 · 查看對照
    KC標誌（ECPSA強制要求）和60 Hz頻率不相容是兩大關鍵障礙；中國50 Hz電機未經設計改造和重新認證，不能直接在韓國銷售。

泰國（TISI）

  • 泰國（TISI） - 工業電動機 · 查看對照
    依據 TIS 2783 的 TISI 產品認證（mod-1 或 mod-5 方案），IE2 最低能效為主要強制要求；中國 IE3 基準通常超過門檻，但仍需單獨取得 TISI 認證。

土耳其（CE同等 / TSE）

  • 土耳其（CE同等 / TSE） - 工業電動機 · 查看對照
    土耳其透過總統令與歐盟生態設計接軌：0.75–375 kW 電機自 2021 年 7 月起強制執行 IE3；CE 標誌被接受，非 CE 產品須通過 TSE 型式檢驗；電網為 400 V 50 Hz（中國為 380 V），大多數電機可承受此輕微電壓差異。

阿聯酋（ESMA / GSO）

  • 阿聯酋（ESMA / GSO） - 工業電動機 · 查看對照
    阿聯酋工業交流電機的主要差距在於 ESMA ECAS 合格評定、GSO/IEC 60034 文件、400 V 50 Hz 電網額定值、帶無線功能產品的 TRA 要求，以及中國 CCC 不被認可。

英國（UKCA）

  • 英國（UKCA） - 工業電動機 · 查看對照
    英國脫歐後的法規與歐盟框架基本一致：保留的生態設計（SI 2021/745）規定的IE3/IE4最低能效標準、《2016年電氣設備安全法規》和《2016年英國電磁相容法規》均適用——與歐盟相比，關鍵額外差距在於以UKCA標誌取代CE標誌，並須指定具有英國地址的英國責任人。

美國（UL/FCC）

  • 美國（UL/FCC） - 工業電動機 · 查看對照
    美國 DOE 節能標準、NEMA Premium 或 IE3 等效能效要求、NEMA MG-1 設計證明、UL 列名以及 IEEE 112 方法 B 測試，是主要差距；僅有 GB/T 1032 測試不能作為美國依據。

越南（工貿部 / 科技部）

  • 越南（工貿部 / 科技部） - 工業電動機 · 查看對照
    越南透過 QCVN 04:2009/BCT 強制要求最低 IE2 及工貿部能效標籤；進口須提供 QUATEST 合格評定報告和符合性聲明及能效證書。
