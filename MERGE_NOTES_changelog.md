# MERGE_NOTES — Changelog surface (`feat/changelog`)

A **static** "changelog-of-proofs" surface for the tender feed: per issue, per market, how many
listings are **new this issue** and how many are **active**. Freshness signal, public and indexable.

## What was added (NEW FILES ONLY, all under `changelog/`)
- `changelog/build_changelog.mjs` — zero-dep Node generator. Reads the public feed
  (`https://asaptic.com/tender/rows.json`, or a local fixture path arg), computes per-market
  `{new, active}` + `totals`, emits `changelog/data/latest.json`.
- `changelog/index.html` — page in the `/demos/` design language. Client-fetches
  `./data/latest.json`; **falls back** to fetching `/tender/rows.json` and computing the identical
  payload client-side (byte-parity verified). Indexable (no `noindex`), bridge nav back to asaptic.com.
- `changelog/data/latest.json` — seed output (regenerated by the cron, see below).
- `changelog/sentinel.mjs` — hygiene scanner (importable + runnable).
- `changelog/fixtures/rows.json` — test fixture, synthetic `AT-TEST-*` ids only.
- `changelog/build_changelog.test.mjs` — `node --test` suite (9 tests).

**Untouched**, as required: `_worker.js`, `tender/**`, `demos/**`, `dev/**`, and all shared files.
This surface is **pure static + a generator** — no route code, no worker changes.

## Wiring needed at merge (NOT done here)
1. **No `_worker.js` change is strictly required** — `changelog/` and `changelog/data/latest.json`
   are served as static assets at `asaptic.com/changelog/`. Confirm no catch-all route swallows it;
   if a SPA/worker fallthrough exists, add `changelog/*` to the static-pass list.
2. **Regeneration on the refresh cron.** The same job that rebuilds `tender/rows.json` should append:
   ```
   node changelog/build_changelog.mjs                      # fetch live feed
   #   or, in-repo before deploy:
   node changelog/build_changelog.mjs tender/rows.json     # use the just-built rows.json
   ```
   This overwrites `changelog/data/latest.json`. It reads only the public feed and writes only
   whitelisted counts, so it is safe to run unattended. If the cron ever skips it, the page's
   client-side fallback recomputes the same numbers live from `/tender/rows.json`, so the surface
   never goes stale/blank.
3. Optional: add `changelog/` to the sitemap (it's a public freshness signal, indexable).

## Moat / disclosure rules honored
- Publishes **only public-derivable counts**: `new_this_issue` is already a public per-row field;
  `active` is a public row filter (`closing_bucket !== "deadline_passed"`). Output is assembled from
  an explicit **whitelist** (`issue_id`, `generated`, `per_market`, `totals`) — never a spread of the
  feed — so upstream-added sensitive fields cannot leak. Tested: fixture carries `withheld:999`,
  `total`, `corpus_total:88888`, `ingest_ts` → none appear in `latest.json`.
- **No** withheld counts, corpus totals, ingest timestamps, or cadence signal beyond the public
  `generated`/`issue_id`.
- Artifact-transparent / process-opaque; no `PCMS` string; no real ref/issuer/date; sample ids are
  `AT-TEST-*` only. Sentinel forbidden-literals are assembled from fragments so it scans its own tree clean.

## Historical deltas — v2 (out of scope here)
v1 shows only current-issue **NEW + ACTIVE** counts. "M expired since last issue" / issue-over-issue
deltas require comparing against a **committed prior snapshot history**, which does not exist yet.
That is deliberately deferred to v2 (add a `changelog/data/history/<issue_id>.json` archive on each
cron run, then diff). Do not add "expired" counts before that snapshot history lands — it would
require a non-public prior state.

## Deadline-passed handling
`isDeadlinePassed(row)` treats BOTH forms as passed: `row.deadline_passed === true` (fixture/boolean
style) and `row.closing_bucket === "deadline_passed"` (the real feed's form, 1508 rows in W33).

## Tests / proof (run in `changelog/`)
- `node --test` → **9 tests, 9 pass, 0 fail**. Covers: per-market counts, sorted markets + summed
  totals, deadline_passed excluded (both forms), latest.json shape, no-forbidden-field-leak self-test,
  CLI generator writes valid file, sentinel trips on forbidden tokens, whole tree clean, sentinel
  self-test on a dirty temp fixture.
- `node sentinel.mjs` → `[sentinel] clean` (exit 0) over the whole `changelog/` tree incl. index.html.
